## Flujos v0

### 1. Radar de oportunidades

Normaliza cada oportunidad con fuente, empresa, modalidad, ubicacion, compensacion, fecha, requisitos, contacto, enlace y vigencia.

### 2. Scoring explicable

Puntaje de 0 a 100:

- 25: retorno economico y calidad contractual
- 20: encaje con experiencia demostrable
- 15: encaje con consultoria metodologica, gestion o IA
- 15: probabilidad de acceso, respuesta o contratacion
- 10: reutilizacion de activos y evidencia existente
- 10: autonomia, impacto y valor estrategico
- 5: velocidad hasta ingreso

Aplicar penalizaciones separadas por tiempo de preparacion, brechas criticas, compensacion desconocida, riesgo reputacional, intermediacion excesiva o requisitos no demostrables.

El puntaje es una estimacion de priorizacion, no una probabilidad estadistica de contratacion, hasta contar con datos historicos suficientes.

### 3. Rutas de conversion

- Empleo: vacante -> analisis -> CV adaptado -> mensaje/carta -> aprobacion -> postulacion -> seguimiento.
- Servicios: empresa/persona -> hipotesis de dolor -> servicio relevante -> evidencia -> mensaje -> discovery -> propuesta -> seguimiento.
- MetodologIA: prospecto -> necesidad -> recurso o servicio existente en metodologia.info -> enlace -> seguimiento bajo reglas de la marca.
- Visibilidad: tema -> evidencia propia -> borrador -> QA factual y de marca -> aprobacion -> publicacion manual o autorizada -> metricas.
